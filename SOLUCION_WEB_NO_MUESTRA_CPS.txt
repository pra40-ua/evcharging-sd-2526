================================================================================
  ✅ PROBLEMA RESUELTO - Los CPs ahora SI aparecen en la web
================================================================================

PROBLEMA ORIGINAL:
Los 5 CPs se ejecutan y aparecen en la terminal de Central, pero NO en la web.

CAUSA:
El Dashboard solo mostraba CPs cuando recibía telemetría de Kafka, pero los CPs
solo envían telemetría cuando hay una sesión de carga activa.

SOLUCIÓN:
Ahora el Dashboard también consulta la base de datos para obtener los CPs
registrados, no solo espera telemetría de Kafka.

================================================================================

CAMBIOS REALIZADOS
------------------

1. ✅ Dashboard sincroniza automáticamente con BD cada 10 segundos
2. ✅ Dashboard carga CPs al iniciar desde la BD
3. ✅ Nuevo botón "🔄 Recargar desde BD" en la interfaz web
4. ✅ Nuevo endpoint POST /api/reload_from_db para recarga manual

================================================================================

CÓMO VERIFICAR QUE FUNCIONA
----------------------------

1. Ejecuta PC_A_RUN.bat normalmente

2. Verifica en los logs del Dashboard que veas:
   [DASHBOARD] ✓ Sincronización automática con BD activada
   [DASHBOARD] ✓ CP cargado desde BD: CP_001 - ACTIVADO
   [DASHBOARD] ✓ CP cargado desde BD: CP_002 - ACTIVADO
   ...

3. Abre la web: http://localhost:8080

4. AHORA DEBERÍAS VER todos los CPs registrados en la tabla

5. Si no los ves, haz clic en el botón "🔄 Recargar desde BD"
