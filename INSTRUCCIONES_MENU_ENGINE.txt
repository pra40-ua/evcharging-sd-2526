================================================================================
  MENU INTERACTIVO DEL ENGINE - Instrucciones de Uso
================================================================================

El Engine del Charging Point tiene un menu LIMITADO con solo las acciones
criticas que simulan interacciones fisicas del CP.

================================================================================

MENU DEL ENGINE
---------------

======================================================================
  CHARGING POINT: CP_001
======================================================================
  Estado: DISPONIBLE (Available)
======================================================================

  ACCIONES DISPONIBLES:
    [1] Conectar vehiculo fisicamente (PLUG)
    [2] Reportar AVERIA (Fault)
    [3] Desconectar vehiculo (UNPLUG)
    [9] Mostrar estado actual
    [0] Ayuda
======================================================================

[CP_001] Accion: _

================================================================================

OPCION [1] - CONECTAR VEHICULO FISICAMENTE
-------------------------------------------

DESCRIPCION:
  Simula que el conductor conecta fisicamente el cable del vehiculo al CP.
  Esta es una accion FISICA que debe detectar el Engine.

CUANDO USAR:
  - Despues de que Central haya autorizado la carga
  - O ANTES, si el conductor conecta el vehiculo anticipadamente

COMPORTAMIENTO:
  SI YA HAY AUTORIZACION DE CENTRAL:
    -> Suministro inicia AUTOMATICAMENTE
    
  SI NO HAY AUTORIZACION AUN:
    -> Engine espera a que Central autorice
    -> Cuando llegue autorizacion, suministro inicia automaticamente

MENSAJES:
  [CP_001] Conductor CONECTA vehiculo fisicamente...
  [CP_001] Vehiculo conectado + Autorizacion previa detectada
  [CP_001] INICIANDO SUMINISTRO automaticamente...
  
  O si no hay autorizacion:
  [CP_001] Vehiculo conectado fisicamente
  [CP_001] Esperando autorizacion de la CENTRAL...

ESTADOS POSIBLES TRAS PRESIONAR [1]:
  - "VEHICULO CONECTADO (Esperando autorizacion de Central)"
  - "CARGANDO (X.XX kWh, XXs)" si ya habia autorizacion

================================================================================

OPCION [2] - REPORTAR AVERIA
-----------------------------

DESCRIPCION:
  Simula un FALLO CRITICO en el Charging Point.
  El CP pasa a estado de AVERIA y notifica al sistema.

CUANDO USAR:
  - Para demostrar tolerancia a fallos
  - Para simular un fallo del hardware
  - Para probar el sistema de notificacion de averias

COMPORTAMIENTO:
  1. Detiene INMEDIATAMENTE cualquier suministro en curso
  2. Marca estado interno: ENGINE_FAULTED = TRUE
  3. Limpia autorizaciones y conexion de vehiculo
  4. En el siguiente HCK, responde KO al Monitor
  5. Monitor detecta KO y notifica AVERIA a Central
  6. Central marca CP como AVERIADO en base de datos
  7. Dashboard web muestra CP en ROJO

MENSAJES:
  [CP_001] REPORTANDO AVERIA...
  ===================================
  [CP_001] AVERIA REPORTADA
  [CP_001] Estado: FAULTED
  [CP_001] Suministro: DETENIDO
  [CP_001] Notificando a Monitor...
  ===================================
  [CP_001] Averia reportada. Monitor notificara a la Central.
  
  (En siguiente HCK)
  [CP_001] HCK_RESP enviado: KO (AVERIA ACTIVA)

ESTADO TRAS PRESIONAR [2]:
  "AVERIA (Faulted)"

RECUPERACION:
  - La averia NO se puede resolver desde el menu
  - Requiere reiniciar el contenedor (simula reparacion fisica)
  - O ejecutar: docker restart engine_CP_001

VERIFICACION:
  - Dashboard web: CP aparece en rojo como "AVERIADO"
  - Central: Logs muestran "CP_001: AVERIA detectada"
  - Nuevas solicitudes a ese CP son DENEGADAS

================================================================================

OPCION [3] - DESCONECTAR VEHICULO
----------------------------------

DESCRIPCION:
  Simula que el conductor DESCONECTA el cable del vehiculo del CP.

CUANDO USAR:
  - Durante una carga (detiene el suministro)
  - Despues de una carga (limpia estado)
  - Para liberar el CP para otro driver

COMPORTAMIENTO:
  1. Marca VEHICLE_PLUGGED = FALSE
  2. Detiene suministro si estaba activo
  3. Limpia autorizacion
  4. Envia STATE UNPLUGGED al Monitor
  5. Monitor notifica a Central
  6. Si hay cola de drivers, se procesa el siguiente

MENSAJES:
  [CP_001] Conductor DESCONECTA vehiculo fisicamente...
  [CP_001] Vehiculo desconectado. Carga detenida.

ESTADO TRAS PRESIONAR [3]:
  "DISPONIBLE (Available)"
  
  O si habia sesion activa:
  "PRE-SUMINISTRO (Sesion activa)" (esperando nuevo driver)

NOTA ESPECIAL:
  Si el CP esta en AVERIA, desconectar solo registra la accion
  pero no cambia el estado de averia.

================================================================================

OPCION [9] - MOSTRAR ESTADO ACTUAL
-----------------------------------

DESCRIPCION:
  Muestra informacion detallada del estado actual del CP.

INFORMACION MOSTRADA:
  - Estado: DISPONIBLE / CARGANDO / AVERIA / etc.
  - Energia acumulada: X.XX kWh
  - Tiempo de carga: XXX segundos
  - Driver actual: DRIVER_XXX
  - Monitor conectado: Si / No
  - Vehiculo enchufado: Si / No
  - Autorizado por Central: Si / No
  - En averia: Si / No

EJEMPLO:
  ======================================================================
    ESTADO ACTUAL DE CP_001
  ======================================================================
    Estado: CARGANDO (5.25 kWh, 105s)
    Energia acumulada: 5.25 kWh
    Tiempo de carga: 105 segundos
    Driver actual: DRIVER_001
    Monitor conectado: Si
    Vehiculo enchufado: Si
    Autorizado por Central: Si
    En averia: No
  ======================================================================

================================================================================

OPCION [0] - AYUDA
------------------

DESCRIPCION:
  Muestra el menu completo de nuevo.

================================================================================

ESTADOS POSIBLES DEL CP
-----------------------

1. "DISPONIBLE (Available)"
   - Sin sesion activa
   - Sin vehiculo conectado
   - Listo para recibir solicitudes

2. "VEHICULO CONECTADO (Esperando autorizacion de Central)"
   - Vehiculo enchufado (presionaste "1")
   - Pero Central aun no ha autorizado
   - Esperando solicitud de driver

3. "AUTORIZADO (Esperando conexion fisica del vehiculo)"
   - Central ha autorizado la carga
   - Pero vehiculo no esta enchufado aun
   - Esperando que presiones "1"

4. "PRE-SUMINISTRO (Sesion activa)"
   - Hay una sesion de driver activa
   - Pero aun no se ha iniciado el suministro

5. "CARGANDO (X.XX kWh, XXs)"
   - Suministro activo
   - Mostrando energia y tiempo en tiempo real

6. "AVERIA (Faulted)"
   - CP en estado de fallo
   - No acepta nuevas solicitudes
   - Requiere reparacion (reiniciar contenedor)

7. "DESCONECTADO (Sin Monitor)"
   - Monitor no conectado
   - CP no operativo

================================================================================

FLUJO COMPLETO EJEMPLO
----------------------

PASO 1: Estado inicial
  Estado: DISPONIBLE (Available)

PASO 2: Driver solicita desde web
  Central autoriza -> Envia START a Engine
  Estado: AUTORIZADO (Esperando conexion fisica)

PASO 3: Conductor presiona "1"
  Vehiculo se conecta fisicamente
  Condiciones cumplidas -> Suministro inicia
  Estado: CARGANDO (0.00 kWh, 0s)

PASO 4: Carga progresa
  Estado: CARGANDO (3.50 kWh, 70s)
  Estado: CARGANDO (7.25 kWh, 145s)
  ...

PASO 5: Conductor presiona "3" (o alcanza objetivo)
  Vehiculo se desconecta
  Carga se detiene
  FIN enviado a Central con datos finales
  Driver recibe ticket
  Estado: DISPONIBLE (Available)

RESUMEN
-------

El menu del Engine es SIMPLE y LIMITADO porque:
  - Solo simula acciones FISICAS del CP
  - Las decisiones de negocio las toma la CENTRAL
  - La autenticacion (RFID) se hace desde web/driver
  - Interfaz enfocada en lo esencial

Las opciones numericas son:
  [1] PLUG - Conectar vehiculo (CRITICO para iniciar suministro)
  [2] FAULT - Reportar averia (CRITICO para tolerancia a fallos)
  [3] UNPLUG - Desconectar vehiculo (CRITICO para liberar CP)
  [9] STATUS - Ver estado detallado (INFORMATIVO)
  [0] HELP - Ver menu (INFORMATIVO)

FLUJO CORRECTO segun enunciado:
  1. Central AUTORIZA (validacion de negocio)
  2. Conductor CONECTA VEHICULO (accion fisica - presionar "1")
  3. Suministro INICIA (automatico cuando se cumplen ambas condiciones)
