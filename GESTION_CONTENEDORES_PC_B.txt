================================================================================
  GESTION DE CONTENEDORES - PC_B
================================================================================

AHORA LOS CONTENEDORES ESTAN ORGANIZADOS Y SE PUEDEN ELIMINAR TODOS JUNTOS

================================================================================

QUE SE HA HECHO
---------------

Todos los contenedores de PC_B ahora tienen etiquetas (labels) de Docker:
  - project=evcharging-pc-b
  - component=engine / monitor / driver
  - cp_id=CP_001, CP_002, etc.

Estas etiquetas permiten filtrar y gestionar los contenedores facilmente.

================================================================================

SCRIPTS NUEVOS DISPONIBLES
---------------------------

1. PC_B_STOP_ALL.bat
   - Detiene TODOS los contenedores de PC_B de una vez
   - Pide confirmacion antes de detener
   - Muestra que contenedores se van a detener

2. PC_B_STOP_ALL.ps1
   - Version PowerShell del anterior
   - Misma funcionalidad, mejor formato

3. PC_B_LIST_CPS.bat
   - Lista todos los contenedores de PC_B que estan corriendo
   - Muestra estado, puertos, etc.
   - Util para verificar que esta corriendo

================================================================================

COMO USAR
---------

OPCION 1: Script automatico (RECOMENDADO)
   > PC_B_STOP_ALL.bat
   
   Te preguntara si estas seguro y luego detendra todos los contenedores.

OPCION 2: PowerShell
   > PC_B_STOP_ALL.ps1

OPCION 3: Comando Docker directo
   > docker stop $(docker ps -q --filter "label=project=evcharging-pc-b")
   
   En Windows PowerShell:
   > docker ps -q --filter "label=project=evcharging-pc-b" | ForEach-Object { docker stop $_ }

================================================================================

VERIFICAR CONTENEDORES
-----------------------

Ver todos los contenedores de PC_B:
   > PC_B_LIST_CPS.bat

Ver solo los Engines:
   > docker ps --filter "label=component=engine"

Ver solo los Monitors:
   > docker ps --filter "label=component=monitor"

Ver todos con detalles:
   > docker ps --filter "label=project=evcharging-pc-b" --format "table {{.Names}}\t{{.Status}}\t{{.Ports}}"

================================================================================

DOCKER DESKTOP
--------------

En Docker Desktop ahora puedes:

1. Filtrar por etiqueta "project=evcharging-pc-b"
2. Ver todos los contenedores agrupados
3. Seleccionar multiples y detenerlos juntos
4. Eliminarlos en grupo si es necesario

COMO:
  - Abre Docker Desktop
  - Ve a la seccion "Containers"
  - Usa el filtro o busca "evcharging-pc-b"
  - Selecciona todos los que quieras
  - Haz clic en "Stop" o "Delete"

================================================================================

FLUJO NORMAL DE USO
--------------------

1. Lanzar CPs:
   > PC_B_RUN.bat
   > Opcion [1] -> Ingresar numero de CPs

2. Trabajar con los CPs:
   - Cada uno en su terminal
   - Usa el menu interactivo

3. Listar CPs corriendo (opcional):
   > PC_B_LIST_CPS.bat

4. Detener todos cuando termines:
   > PC_B_STOP_ALL.bat
   > Confirmar con "S"

================================================================================

VENTAJAS
--------

ANTES:
  - Tenias que cerrar cada terminal manualmente
  - O recordar el nombre de cada contenedor
  - Comandos largos: docker stop engine_CP_001 engine_CP_002 ...

AHORA:
  - Un solo comando: PC_B_STOP_ALL.bat
  - O desde Docker Desktop en grupo
  - Mas organizado y facil de gestionar

================================================================================

COMANDOS UTILES
---------------

Listar todos los contenedores de PC_B:
  docker ps --filter "label=project=evcharging-pc-b"

Detener todos:
  PC_B_STOP_ALL.bat

Ver logs de un contenedor especifico:
  docker logs engine_CP_001

Ver logs de todos los Engines:
  docker ps -q --filter "label=component=engine" | ForEach-Object { docker logs $_ }

Eliminar contenedores detenidos:
  docker container prune --filter "label=project=evcharging-pc-b"

================================================================================

COMPATIBILIDAD
--------------

Estos cambios son compatibles con:
  - Modo clasico (1 CP + 1 Driver)
  - Modo multiple (hasta 5 CPs)
  - Windows y PowerShell
  - Docker Desktop

No afecta:
  - Funcionamiento de los CPs
  - Comunicacion con la Central
  - Dashboard web
  - Telemetria y Kafka

================================================================================

SOLUCION DE PROBLEMAS
----------------------

Si PC_B_STOP_ALL.bat no funciona:
  1. Verifica que Docker Desktop este corriendo
  2. Ejecuta: docker ps
  3. Usa el comando manual:
     docker ps -q --filter "label=project=evcharging-pc-b" | ForEach-Object { docker stop $_ }

Si los contenedores no se detienen:
  1. Cierra las terminales de PowerShell (Ctrl+C)
  2. Ejecuta: docker ps (para ver cuales siguen corriendo)
  3. Fuerza la detencion: docker kill [nombre]
