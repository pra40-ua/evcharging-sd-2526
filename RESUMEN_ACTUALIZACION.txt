🎯 CARACTERÍSTICAS PRINCIPALES
--------------------------------------------------------------------------------

1. ✅ HASTA 5 CPs SIMULTÁNEOS
   - Cada CP tiene un ID único (CP_001, CP_002, ...)
   - Cada CP usa un puerto único (5001, 5002, 5003, ...)
   - Cada CP se registra automáticamente en la Central

2. ✅ TERMINALES INDEPENDIENTES POR CP
   - Terminal 1: ENGINE (menú interactivo + mensajes)
   - Terminal 2: MONITOR (comunicación con Central)

3. ✅ ESTADO VISIBLE Y CLARO
   Cada terminal de Engine muestra:
   - ID del Charging Point
   - Estado actual (DISPONIBLE, CARGANDO, etc.)
   - Menú de opciones
   - Energía acumulada en tiempo real
   - Tiempo de carga

4. ✅ COMUNICACIONES OCPP-LIKE VISIBLES
   Todos los mensajes se muestran claramente:
   - Mensajes recibidos del Monitor/Central
   - Mensajes enviados a Monitor/Central
   - Formato visual con emojis y banners

5. ✅ SIMULACIÓN DE ACCIONES DEL CONDUCTOR
   Desde el menú interactivo puedes:
   - Enchufar/desenchufar vehículos
   - Ver el estado en tiempo real
   - Simular acciones físicas
   - Monitorear el progreso de la carga

🚀 CÓMO USAR (QUICK START)
--------------------------------------------------------------------------------

PASO 1: Ejecutar el script principal
   > PC_B_RUN.bat

PASO 2: Seleccionar modo
   > Opción [1] para múltiples CPs

PASO 3: Indicar número de CPs
   > Número: 3  (por ejemplo)

PASO 4: Esperar a que se abran las terminales
   - Se abrirán 6 ventanas (3 CPs × 2 terminales cada uno)

PASO 5: En cada terminal de Engine
   - Teclear "p" para enchufar un vehículo
   - Ir a la web y autorizar la carga
   - Ver cómo se inicia la carga automáticamente
   - Teclear "s" para ver el estado
   - Teclear "d" para detener

🔧 CONFIGURACIÓN TÉCNICA
--------------------------------------------------------------------------------

PUERTOS ASIGNADOS:
- CP_001: Engine en puerto 5001
- CP_002: Engine en puerto 5002
- CP_003: Engine en puerto 5003
- CP_004: Engine en puerto 5004
- CP_005: Engine en puerto 5005

CONTENEDORES DOCKER:
- engine_CP_001, engine_CP_002, ... (Engines)
- monitor_CP_001, monitor_CP_002, ... (Monitors)

VARIABLES DE ENTORNO (por CP):
- CP_ID: Identificador único
- ENGINE_PORT: Puerto del Engine
- KAFKA_SERVER: Servidor Kafka (para telemetría)
- CENTRAL_IP: IP de la Central (PC_A)
- CENTRAL_PORT: Puerto de la Central (5000)

🛑 CÓMO DETENER EL SISTEMA
--------------------------------------------------------------------------------

OPCIÓN 1 (Recomendada): Ctrl+C en cada terminal
   - Presionar Ctrl+C en cada ventana de PowerShell
   - Los contenedores se detendrán limpiamente

OPCIÓN 2: Comando Docker
   docker stop engine_CP_001 engine_CP_002 monitor_CP_001 monitor_CP_002

OPCIÓN 3: Detener todos los contenedores
   docker stop $(docker ps -q)
